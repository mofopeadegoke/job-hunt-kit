# Resume versions

Every version has the same content as A-baseline (your corrected master). Each changes one thing.

| File | The one change |
| --- | --- |
| A-baseline | Corrected master resume (2 pages) |
| B-two-column | Skills, education and achievements in a left sidebar (fits on 1 page as a side effect) |
| C-header-contact | The two contact lines moved into the page header (fancyhdr) |
| D-icons | Symbol-font icons before each contact item |
| E-section-names | Creative headings: About Me, What I Know, Where I've Worked, Things I've Built, Where I Studied, Wins |
| F-skills-table | Skills shown as a 5-column table grid |
| G-no-unicode | The pdfglyphtounicode / \pdfgentounicode block removed |
| H-dates | Dates written as 06/2025 - 09/2025 |

I-word.pdf (same content typed into Word or Google Docs) is yours to make.

Compile every .tex in the same place you compile your real resume (e.g. Overleaf), so results reflect the PDFs you actually send.
